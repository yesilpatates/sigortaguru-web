# SigortaGuru Web

GitHub Pages üzerinde çalışacak statik SigortaGuru sitesi.

## Yapı
- Ana sayfa, hakkımızda, ürünler, blog, iletişim
- 6 ürün detay sayfası
- WhatsApp tabanlı teklif formu
- Responsive tasarım
- SEO meta alanları, robots.txt, sitemap.xml, CNAME
- Marka renkleri: #083941, #189593, #70B7B5
- Tipografi: Outfit + Poppins

## Yayın
Repository GitHub Pages ile ana branch kökünden yayınlanabilir. `CNAME` dosyası `www.sigortaguru.com` için hazırdır.

## Yayın öncesi zorunlu kontroller
1. Resmi logo dosyasını orijinal vektör/PNG ile değiştir. Mevcut wordmark marka kılavuzundan teknik önizleme için çıkarılmıştır.
2. KVKK/Gizlilik/Çerez metinlerini şirketin gerçek veri sorumlusu bilgileriyle hukuk danışmanına doğrulat.
3. Şirket ticari unvanı ve açık adresi doğrulanınca footer/iletişim alanına ekle.
4. Gerekirse Analytics/Search Console doğrulama kodlarını ekle.
5. DNS yönlendirmesi tamamlandıktan sonra HTTPS zorlamasını etkinleştir.
